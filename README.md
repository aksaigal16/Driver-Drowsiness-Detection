# Driver-Drowsiness-Detection-
Real-time Driver Drowsiness Detection System using Python, OpenCV, and MediaPipe to monitor eye closure and head movements, with Arduino Uno integration to trigger alerts and reduce motor speed when drowsiness is detected.

- **Real-Time Drowsiness Detection:** Detects signs of driver drowsiness using facial landmarks and Eye Aspect Ratio (EAR).
- **Head-Nod Detection:** Monitors head movements to identify possible signs of fatigue.
- **Motor Speed Control:** Reduces DC motor speed when drowsiness is detected using Arduino Uno and an L298N motor driver.
- **Python-Arduino Communication:** Uses serial communication to send detection commands from Python to Arduino.
- **Alert System:** Triggers an alert when driver drowsiness is detected.
